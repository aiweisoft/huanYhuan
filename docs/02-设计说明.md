# 缓一缓 · 设计说明（v0.2）

> v0.2 起树洞内容上云（uniCloud 支付宝空间），后端细节见 `docs/03-后端说明.md`。

## 1. 信息架构

```
tabBar
├─ 树洞（首页）          情绪流：发帖、筛选、抱一下
│   ├─ 写下此刻           发帖页（含危机提示）
│   └─ 单条树洞           完整正文 + 回应
├─ 读一点（内容库）       搜索、分类、收藏
│   └─ 文章详情           正文、字号、收藏、原文链接、免责声明
└─ 我的                   匿名身份、我的帖子、收藏、设置
    ├─ 求助资源           热线、就医、陪伴话术
    └─ 关于               理念、免责声明、数据说明、导出
```

## 2. 关键产品决策

| 决策 | 选择 | 理由 |
|---|---|---|
| 互动形态 | 只能「抱一下」+ 预设回应 | 去掉攻击与攀比的入口，降低发帖心理成本 |
| 数据展示 | 不显示粉丝/点赞/排名 | 比较是内耗的主要来源 |
| 首版后端 | 本地优先 + 云端同步 | 匿名也能发，不强制注册；本地缓存保证弱网可用 |
| 内容来源 | 编辑部内容 + 开放 RSS | 可控、可审、无版权灰区 |
| 危机处理 | 关键词触发卡片，不阻断发布 | 阻断会把人推走；给出口比拦下来更有用 |

## 4. 数据模型

v0.2 起树洞内容存在云端（uniCloud 支付宝空间），客户端只保留三样本地数据：

```
huanhuan.v1          身份 + 文章收藏/已读 + 设置
huanhuan.posts.v1    树洞列表缓存（离线可看）
huanhuan.pending.v1  待同步队列（发帖/拥抱/回应失败后重试）
huanhuan.anon.v1     本机匿名标识 anonId
```

- 云端集合与字段见 `docs/03-后端说明.md`
- 帖子按 `cursor`（上一条的 `at`）翻页，不用 offset
- 情绪 id：`anxious / low / sleep / friction / social / tired`
- 文章仍是只读数据：`common/data/articles.js`（内置）+ `common/data/articles.generated.js`（RSS 导入）
- 文章字段：`id, title, category, source, summary, body[], url?, at?, minutes?, sample?`
- 文章本身不上云，只有收藏 / 已读状态跟账号或本机走

## 5. 危机干预设计

**触发**：`common/crisis.js` 里的正则，覆盖自杀、自残、轻生、不想活、想死（排除「想死你了」）等表达。

**展示位置**：

1. 发帖页：输入过程中实时出现，不阻断发布。
2. 树洞详情：帖子命中时出现在正文下方。
3. 文章详情：正文命中时出现在文末。

**卡片内容**：一句接住的话 + 12356（全国统一心理援助热线）+ 010-82951332（北京危机干预）+ 120，全部可点击拨号，另有「更多求助方式」入口。

**原则**：不说教、不承诺保密、不替代专业判断；文案避免「你应该」。

## 6. 视觉规范

| 项 | 值 |
|---|---|
| 背景 | `#F7F5F2`（暖白） |
| 卡片 | `#FFFFFF`，圆角 28rpx，无重阴影 |
| 主色 | `#55707F`（雾蓝），用于行动与选中 |
| 强调 | `#BE8567`（陶土色），用于收藏、危机卡片边框 |
| 正文 | `#262421`，辅助 `#8C8680`，极弱 `#C4BDB6` |
| 字号 | 标题 40–46rpx，正文 30–31rpx，辅助 21–25rpx |
| 行高 | 正文 1.75–1.95，长文优先可读性 |

情绪标签不用高饱和红黄，统一低饱和色块，避免「警告感」。

## 7. 内容管线

```
编辑部 / 后台「文章管理」
   → 云端 huanhuan-articles（status: published）
   → App 与 H5 共用 common/articles.js：本地缓存优先 + 云端静默刷新
   → 云端为空或离线时，回落到内置 12 篇（common/data/articles.js）

可选：RSS 批量导入
feeds.json / 命令行 URL
   → tools/rss-import.mjs（fetch + 正则解析 RSS/Atom + 去标签）
   → common/data/articles.generated.js
   → 后台导入 → 云端
```

- 零依赖，Node 18+ 自带 fetch。
- 每条保留 `url`，详情页给「原文」入口，不做全文搬运。
- 导入结果仍需人工过一遍：营销号、标题党、带诊断结论的内容一律不上。
- 后台改文章不用发版；App 下次打开会拿到最新列表。
