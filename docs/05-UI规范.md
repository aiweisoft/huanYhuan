# 缓一缓 · UI 规范（v0.5 · 精致玻璃态）

> 参考 `ui-ux-pro-max` 的优先级规则（对比度、触控、图标、留白），
> 结合本项目「简单、克制、暖白」的定位落地。**没有照搬它推荐的深色 OLED 主题和 Lora/Raleway 字体**：
> 深色不适合助眠以外的树洞阅读场景，Lora/Raleway 也不覆盖中文。

## 2. 玻璃态（全项目统一）

### 2.1 结构：五层

1. **柔光背景** —— `glass-shell` 里 5 团径向渐变的圆形光斑（雾蓝 / 陶土 / 青绿 / 淡紫），固定定位，`pointer-events: none`
2. **玻璃填充** —— 从 `rgba(255,255,255,0.54)` 到 `0.34` 的 165° 线性渐变
3. **亮边 + 顶部内高光** —— `1px solid rgba(255,255,255,0.8)` + `inset 0 1px 0 rgba(255,255,255,0.95)`
4. **极淡投影** —— `0 12rpx 30rpx rgba(74,64,54,.08)`，外加一圈 `0 0 0 1px rgba(120,110,98,.045)` 的收边
5. **磨砂** —— `backdrop-filter: blur(18px) saturate(160%)`

再叠一层 `radial-gradient(120% 90% at 100% 0%, rgba(255,255,255,.5), transparent 58%)`，
让卡片右上角先亮起来，玻璃才有厚度。

### 2.2 参数表

| 元素 | 填充 | blur | 圆角 |
|---|---|---|---|
| 页面大卡（树洞卡、文章卡、我的分组） | `0.54 → 0.34` | 18–20px | 30–32rpx |
| 卡内胶囊（抱一下、筛选、标签） | `rgba(255,255,255,0.46–0.55)` | 12–14px | 全圆 |
| 弹窗 | `rgba(255,255,255,0.86)` | 26px | 32rpx |
| 底部操作条 | 渐隐到页面底色 + blur 10px | 10px | — |
| 播放条（暮色） | `rgba(31,27,24,0.82)` | 22px saturate 140% | — |

### 2.3 硬规则

- **透明度锁定 0.34–0.54**。低于 0.3 会污染正文对比度；不支持 `backdrop-filter` 时退化成半透明白仍可读。
- **一页只允许两级玻璃**：卡片 → 卡内胶囊。不要玻璃套玻璃套玻璃。
- **`scroll-view` 内不用 `backdrop-filter`**：Chromium 在滚动容器里采样会错位出方块。分类胶囊因此只用半透明白 + 亮边。
- **深字压浅玻璃**。不要白字压浅玻璃（`1.1.png` 的方案只有约 2.0:1）。
- 强调色 `#9FB5D0` 这类浅冷色只能做图形和暗底文字，不做浅底小字。

### 2.4 组件

`components/glass-shell/glass-shell.vue`，easycom 自动注册，无需 import：

```vue
<glass-shell>              <!-- 暖白 -->
<glass-shell variant="dusk"> <!-- 暮色，仅「听一点」 -->
```

页面用它包住整页根节点，**不要再各自复制 aurora 标记**：

```vue
<template>
	<glass-shell>
		<view class="page">…</view>
	</glass-shell>
</template>
```

`.page` 只留 `min-height: 100vh` 和 padding，不写 `background`。

## 6. 图标

- 播放/暂停/上一首/下一首用 **CSS 形状**绘制，不用 `▶ ❚❚ ‹‹` 字符
- 「抱一下」用 **内联 SVG 背景图**（`data:image/svg+xml`）：一颗描边的心，`viewBox 0 0 24 24`、线宽 2.1、圆头圆角
  - 常态 `#3E5B69`、已抱过 `#3F5C4C`，两条 `background-image` 由 `.hug.hugged` 切换，不依赖 `currentColor`
  - 卡片里 36rpx、详情页 40rpx；不用 emoji，也不再用 `⌒` 这类字符充当图标
  - 试过但放弃：双臂环抱一颗心（20px 下心看不清）、两个人并肩（缩到 40rpx 像虫子）
- tabBar 用 96×96 PNG，图形实际占比约 65–70px，避免视觉偏小
- 不使用 emoji 当图标

## 7. 状态

- 加载：一行「正在加载…」，不做骨架屏闪烁
- 空：一句说明 + 一个主按钮
- 错误：就近 toast，不弹大弹窗
- 离线：读缓存，提示「先看缓存」

- 所有固定元素避开 `env(safe-area-inset-bottom)`

## 10. 听一点「暮色」主题

只有「听一点」用深色，其余页面保持暖白。参考截图里的「暖底 + 冷玻璃 + 冷强调」逻辑。

| 角色 | 色值 | 对比度 |
|---|---|---|
| 页面背景 | `#26211D` | — |
| 卡片 | 白 0.03–0.08 玻璃 + 三团彩色柔光 | — |
| 卡片选中 | 同上 + `rgba(159,181,208,0.5)` 边框 | — |
| 主文字 | `#F2EFEA` | 11.84:1 |
| 次文字 | `#B9B1A8` | 6.41:1 |
| 弱文字 | `#9B948C` | 5.32:1 |
| 强调 / 进度 | `#9FB5D0` | 6.46:1 |
| 播放条背景 | `rgba(31,27,24,.82)` + blur 22px | — |
| 播放按钮 | `#9FB5D0` 底 + `#26211D` 图标 | 7.58:1 |

规则：

- 强调色只用于进度、选中、播放状态，不做大面积背景
- 白字只出现在标题和主按钮
- 底部 tabBar 仍保持浅色（图标是浅色底设计的，暂不动态换肤）

播放实现（v0.6 起，照 my-music）：

- 听一点**只播本机文件**：自带 5 段声音首次进入时从 APK assets 复制到 `_doc/audio/`，之后和用户添加的音频走同一条播放链路
- 导入时一律把 `content://` 复制到应用私有目录 `_doc/audio/`，`path` 只指向副本（SAF 授权是进程级的，直接引用原路径杀进程后会失效）
- 复制按 URI 哈希命名，避免不同目录同名文件互相覆盖；全程用字符串路径构造 `File` / `FileOutputStream`（桥接对象当构造参数会静默失败）
- 播放：单例 + 每首重建 `InnerAudioContext`（旧的先 `destroy()`，避免 -99），`autoplay = true`，`onCanplay` 里再补一次 `play()`
- 播放前校验文件存在；副本丢失时列表标「文件已失效」，不把无效路径交给播放器
- UI 状态用事件 + 500ms 轮询双保险；睡眠定时到点只暂停

## 11. 听一点：本机音频的导入与移出

- 入口：列表上方「＋ 从手机添加音频」；有音频时右上角出现「管理」，进入后每条右侧出现 64rpx 圆形减号
- 导入：原生 `ACTION_OPEN_DOCUMENT` 选音频 → 复制到 `_doc/audio/`（按 URI 哈希命名）→ 读 ID3 取标题和时长 → 入库；复制失败会弹窗显示原因，不静默跳过
- 移出：只删应用里那份副本，不动手机里的原文件；正在播放的那条被移出会停止播放并收起播放条
- 副本丢失：列表项显示橙色的「文件已失效，请移出后重新添加」，点击不播，避免把无效路径交给播放器
- 数据模型：`{ id, title, duration, uri, path, broken }`；`uri` 保留原始 `content://`，副本丢了还能重新复制
- 空状态：「还没有添加音频」+ 一句引导
- 不用长按、不用侧滑：管理入口可见

## 12. 写一点：情绪标签与自定义

- 单行横向滚动（`scroll-view scroll-x`），与首页分类胶囊同一套样式：玻璃底 + 1px 亮边 + 顶部内高光，高 72rpx、字号 25rpx、间距 14rpx
- 顺序：「＋ 自定义」固定在最前 → 6 个预设；放不下就左右滑，不换行
- 选中：实心 `#3E5B69` + 白字 + 同色投影；未选中：玻璃底 + `#4A453E`
- 自定义入口：标题行右侧「自定义」文字链，点开底部玻璃输入条，最多 6 个字，自动去掉空白；标签行末尾也有「＋ 自定义」，避免只靠右上角
- 自定义生效后：自定义标签排在行首并选中，6 个预设全部取消选中，入口变成「改一下」；输入条里可以「不用自定义了」清掉
- 数据模型：`mood` 仍是 6 个枚举之一，决定分组、颜色和筛选；`moodLabel` 只覆盖显示文字，服务端存 `mood_label`，列表、详情、我的都优先显示它
- 离线发帖的 pending 队列也带 `moodLabel`，联网后补发时一起提交
